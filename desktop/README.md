# Desktop Diagnostic Tool (Phase 6)

C# WPF application (.NET 8, MVVM, no code-behind logic). Automotive-style dark
diagnostic UI: dashboard, lighting/door/ignition/horn panels, battery status,
UART connection, live logs, fault window, event history, status LEDs.
Speaks the framed protocol defined in `docs/protocol/` (BCM-ICD-001).
